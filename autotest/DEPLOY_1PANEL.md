# 1Panel 面板部署文档

适用于已经装好 [1Panel](https://1panel.cn/) 的服务器，用面板的容器编排 + 网站反代功能部署，不用手敲 Nginx 配置。基础的 Docker 概念和目录挂载说明见 [DEPLOY_DOCKER.md](DEPLOY_DOCKER.md)，这里只讲 1Panel 里的操作路径。

## 一、上传代码

1Panel 左侧「**文件**」里没有 git 功能，用面板自带终端最方便：

1. 左侧「**主机**」→「**终端**」，打开一个 SSH 会话
2. 找个目录放项目，1Panel 默认应用一般放在 `/opt/1panel/apps` 下，但这个项目不是从应用商店装的，放哪都行，比如：
   ```bash
   cd /opt
   git clone <你的仓库地址> autotest
   cd autotest
   cp .env.example .env
   vi .env    # 填 AUTOTEST_USER / AUTOTEST_PASS
   ```

也可以本地打包好 zip，用「文件」功能上传到服务器再解压，效果一样。

## 二、用容器编排启动

1. 左侧「**容器**」→「**编排**」→「**创建编排**」
2. 名称随意填（如 `autotest`），**编排路径**选到刚才的项目目录 `/opt/autotest`（该目录下已有 `docker-compose.yml`，1Panel 会直接识别）
3. 点「**确认**」，1Panel 会执行 `docker compose up -d --build`，构建过程可以在面板里看实时日志
4. 构建完成后，「容器」→「容器列表」里能看到 `autotest` 容器，状态正常运行

后续可以直接在面板上操作，不用回终端：
- 点容器进「**日志**」标签看实时输出
- 「**终端**」标签直接进容器排查
- 「**重启**」「**停止**」按钮管理生命周期

## 三、开放访问

有两种方式，**推荐方式二**（不直接暴露端口，走 HTTPS 反代）。

### 方式一：直接开端口

左侧「**安全**」→「**防火墙**」（或「安全组」，取决于云厂商是否托管），放行 `5000` 端口，然后 `http://服务器IP:5000` 直接访问。简单但公网直接暴露一个裸 HTTP 端口，不推荐长期这样用。

### 方式二：网站反向代理 + HTTPS（推荐）

1. 左侧「**网站**」→「**创建网站**」→选「**反向代理**」
2. 域名填你准备好的子域名（如 `autotest.yourdomain.com`），要提前把域名解析到服务器 IP
3. 代理地址填 `http://127.0.0.1:5000`
4. 创建完成后，进这个网站的「**HTTPS**」设置，选「**Let's Encrypt**」申请免费证书，开启「**强制 HTTPS**」

这样对外只暴露 443，5000 端口只在 127.0.0.1 上监听即可，防火墙不用放行 5000。

## 四、数据持久化 / 查看数据

`docker-compose.yml` 里挂载的 `configs/`、`reports/`、`.env`、`auth.json` 都在宿主机的项目目录下，直接用 1Panel「**文件**」功能就能浏览、编辑、下载报告文件，不需要进容器。

## 五、验证码场景传 auth.json

如果目标系统登录页有验证码，先在本地电脑跑：

```bash
python cli.py login <登录页地址>
```

生成的 `auth.json` 直接用 1Panel「**文件**」的上传功能，上传覆盖到项目目录下的 `auth.json` 即可，不用重启容器（下次执行会自动读取新的登录态）。

## 六、更新

在「主机」终端里：

```bash
cd /opt/autotest
git pull
docker compose up -d --build
```

或者回到「容器」→「编排」，找到 `autotest` 编排，点「**重新构建**」，效果一样。

## 常见问题

- **容器起来了但访问 502**：反代地址端口和容器实际映射端口对不上，检查 `docker-compose.yml` 里 `ports` 是不是 `5000:5000`，反代地址是不是 `127.0.0.1:5000`。
- **页面运行中崩溃 / Chromium 报错**：`docker-compose.yml` 里已设 `shm_size: 1gb`，如果目标页面特别重可以在编排里改大到 `2gb` 后重新构建。
- **日志在哪看**：容器详情页「日志」标签，不用去服务器上敲 `docker logs`。
