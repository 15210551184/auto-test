新建系统

多个系统账号不一样？别把真实密码直接填在这——去 .env 里给这个系统单独起一对变量名（如 SYSA_USER / SYSA_PASS）， 这里账号密码框改填 ${env:SYSA_USER} / ${env:SYSA_PASS} 引用，密码就只留在服务器的 .env 里，不会明文存进这个系统的配置文件。
标志元素用来判断登录态是否还有效：填一个登录后才会出现的元素， 比如侧边菜单 .el-menu。留空则只看是否跳回登录页。
